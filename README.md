Programa da cadeira de Análise de Algoritmos (INF1721) da PUC-Rio, ministrado pelos professor Sardinha e Molinaro - versão beta.
O arquivo .ctb (CherryTree) é um resumo separado por tópicos para alunos curiosos que queiram explorar o curso usando a organização provida pelo editor de texto.
Códigos do professor ou feitos em IA estão devidamente indicados, bem como a bibliografia.

OBS.: Ao baixar o CherryTree, já há versão estável e portável 1.7.0 (como novos emojis!). Porém recomenda-se o uso do CherryTree versão 1.5.0, devido a possível mudança/regressão no mecanismo de seleção de fontes do Pango 1.57/1.58,
que exige fonte colorida para exibir emojis e acaba resultando em erro de renderização no Windows.
